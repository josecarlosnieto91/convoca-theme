Tema FSE (Full Site Editing) moderno, basado en bloques, accesible (WCAG 2.1 AA), responsive y preparado para el ecosistema Convoca.

== Description ==

Convoca es un tema de bloques moderno diseñado para organizaciones, asociaciones y proyectos con impacto social. Totalmente compatible con el editor de sitio completo (FSE) de WordPress.

= Características =

* **Full Site Editing** — Edita header, footer, plantillas y todas las partes del sitio desde el editor de bloques
* **WCAG 2.1 AA** — Accesibilidad verificada, contraste de color, navegación por teclado
* **Modo oscuro** — Soporte nativo con toggle y detección de preferencias del sistema
* **Responsive** — Diseño adaptativo mobile-first
* **Patrones de bloque** — Patrones predefinidos para actividades, proyectos, equipo y más
* **Estilos globales** — Paleta de colores, tipografía y espaciado configurables desde el editor
* **Rendimiento** — CSS mínimo, sin dependencias JavaScript pesadas, compatible con caching
* **Traducciones** — Preparado para traducción (.pot incluido), compatible con plugins multilingües

= Compatibilidad =

* WordPress 6.4+ (FSE completo)
* PHP 8.1+
* Plugins del ecosistema Convoca (Core, Enroll, Members, Gateway, Shifts, Publisher)
* WooCommerce
* Yoast SEO, Rank Math
* LiteSpeed Cache, WP Rocket

== Installation ==

1. En el administrador de WordPress, ve a Apariencia → Temas → Añadir nuevo
2. Sube el archivo ZIP del tema
3. Actívalo
4. Ve a Apariencia → Editor para personalizar plantillas y estilos

== Frequently Asked Questions ==

= ¿Es un tema de bloques o clásico? =

Es un tema de bloques (block theme) compatible con Full Site Editing. Usa theme.json para la configuración global y plantillas HTML para todas las partes del sitio.

= ¿Funciona con constructores de páginas? =

Está optimizado para el editor de bloques nativo de WordPress. Puede funcionar con Elementor o Beaver Builder, pero la experiencia óptima es con el editor de bloques.

= ¿Soporta WooCommerce? =

Sí, incluye estilos compatibles con WooCommerce y se integra con los plugins de pago del ecosistema Convoca.

= ¿Cómo activo el modo oscuro? =

El tema incluye un toggle de modo oscuro. También respeta la preferencia del sistema operativo (prefers-color-scheme).
